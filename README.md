# Практична №7
Шевчук Богдан, 32-IST. Номер у журналі 24.
Відкрити цю папку в Android Studio. Виконати `flutter pub get`, `flutter run`.
Перевірка: `dart analyze`, `flutter test`. APK: `../apk/practical_07.apk`.
Справжні скриншоти Android: `screenshots/`.
Навчальні форми не підключені до сервера: діалоги демонструють локальний результат.
Репозиторій: https://github.com/bshevchuk209/practical_07 . Посилання Appetize.io та QR-коди студент додасть самостійно.
